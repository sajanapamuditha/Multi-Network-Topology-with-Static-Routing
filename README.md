Devices and Configuration

Router0 (R0) – Connects Network A to the Router1 via serial link.
Router1 (R1) – Connects to Network C and provides routing between subnets.
Switches – Used for LAN device connectivity in each network.
Server – Provides network services in Network A (e.g., DHCP, DNS, or HTTP).
Access Point – Extends wireless connectivity to laptops in Network A.

Routing

Static or dynamic routing is configured to allow communication between:
Network A ↔ Network C
Network A ↔ Network B ↔ Network C
